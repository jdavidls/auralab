El proyecto utiliza poetry, debes utilizar `poetry run python` para ejecutar scripts.

Emplazaremos los scripts de testeo en el directorio 'scripts'.

Cada funcionalidad debe tener un test unitario en el directorio 'test' utilizando unittest.

usaremos plotly con un tema 'dark' para mostrar graficas y resultados.

preguntame antes de hacer grandes rediseños, proponme el diseño y consensua conmigo los pasos a seguir.
